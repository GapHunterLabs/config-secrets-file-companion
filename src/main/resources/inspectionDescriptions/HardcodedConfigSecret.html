Reports a suspected secret hardcoded in a configuration file (.properties, .env and its variants, .yml, .yaml): an AWS access key, a GitHub or Slack token, a JWT, a PEM private key, or a high-entropy value assigned to a key whose name looks like a secret.

Values pasted into a config file "just for local testing" are a common way secrets end up committed. Detection is static text analysis (known credential formats plus a key-name and entropy heuristic); nothing is sent over the network.
